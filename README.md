## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка статики:

```bash
npm run build    # -> out/
```

## Как обновить контент

Весь текст сайта — в [`content/`](content), правится без пересборки логики:

| Файл | Что внутри |
|---|---|
| `site.json` | Название, контакты, навигация шапки/футера |
| `services.json`, `research.json`, `learning.json`, `tech.json` | Карточки/строки соответствующих страниц |
| `works.json` | Продукты, проекты, портфолио |
| `team.json` | Люди, направления |
| `product-univerkon.json` | Контент шаблона страницы продукта |
| `blog-posts.json`, `mailstack-toc.json`, `hosting-checklist.json` | Блог |
| `legal.json` | Реквизиты (массив пар [лейбл, значение]) |

## Структура

```
aplicon-ru.github.io/
├── InBox/          ← исходный архив хендоффа от дизайнера, как пришёл
├── design-ref/     ← хендофф дизайна: README, токены, кликабельный прототип
├── content/        ← контент сайта в json
├── src/
│   ├── app/        ← маршруты (App Router)
│   ├── components/ ← шапка, подвал, бейдж статуса, компоненты статьи
│   ├── lib/        ← загрузка контента, active-nav, Метрика
│   └── styles/     ← tokens.css, копия из design-ref
└── AGENTS.md       ← правила проекта, читать перед правками
```

## Стек

Next.js 16 (App Router, статический экспорт), React 19, Tailwind 4.
Дизайн-токены — из `design-ref/tokens.css`, проброшены в Tailwind через
`@theme inline`. Шрифты (Unbounded/Manrope/Silkscreen) — самохостинг через
`next/font/google`. Сборка отдаёт статику в `out/` — GitHub Pages.

Домен `aplicon.ru` — кастомный, в корне (не подкаталог), поэтому
`NEXT_PUBLIC_BASE_PATH` не используется в отличие от других сайтов
экосистемы на `*.github.io/<repo>`.
